Academic Research Tool
--

A multi-agent AI application that takes a research question, then searches, filters, ranks and summarises academic articles. A planner agent creates search terms and coordinates a retrieval agent (arXiv, OpenAlex and CORE APIs), a processing agent (filtering, ranking and summarising) and a storage agent (final results in markdown with Harvard references). Each agent is powered by a local LLM run through Ollama.

Download the code: [academicresearchtool.zip](/docs/IntelligentAgents/academicresearchtool.zip)

Installation and usage instructions are in the `README.md` inside the zip.
